# AutoNext: public-market alignment
Date: 2026-11-16

## User direction
AutoNext is for public-market companies. The original proposal's public/private universe is superseded for implementation scope, not silently rewritten. Private companies may be contextual competitors, but are not ranked as investable public securities.

## Preserve the ambition
Retain the original evidence-first, point-in-time, transparent-judgment architecture, company/security separation, falsifiers, source independence, independent specialist review, causal market models, forecasts and calibration. The first executable slice builds a trustworthy foundation for those capabilities.

## Implemented first workflow
Import public evidence -> select security and cutoff -> inspect technical/commercial claims -> compare expectations with actuals -> invert a valuation scenario -> identify a thesis-changing event -> compare saved runs.

This is a deterministic research object, not an AI-written memo masquerading as a model.

## Next integration boundaries
1. Real primary-source filing and earnings ingestion with retained documents, publication timestamps, amendments and schema validation.
2. Licensed market-price and consensus adapters with entitlement tracking, timestamped snapshots, FX and corporate actions. Never relabel model estimates as consensus.
3. Explicit operating forecasts, financing proceeds, cash burn/runway and dilution bridge. Do not treat scientific success as per-share success.
4. Specialist photonics models for qualification, yields, capacity, design wins and revenue recognition; separate claims from investment inference.
5. Connect Scout/Radar for discovery, Assay for verification, Conviction for recorded theses through versioned adapters, not assumed integrations.
6. Multi-user permissions before organisational rollout; confidential evidence must not leak into public-stock decisions or shared derived outputs.
7. Independent committee and causal/scenario modules; each contribution must cite evidence and change a decision-relevant conclusion.
8. Compare like-for-like cohorts with quality, confidence and research priority kept separate. No universal score until weights, abstention and sensitivity tests are validated.
9. Evaluate historical decisions using frozen evidence; include failures/delistings, source-selection bias and hindsight tests.

## Acceptance bar before calling this useful for live research
Run five real public photonics securities with primary sources, validate material inputs manually, add a new filing, and verify exact changes. Demonstrate one non-obvious useful diligence question, reproducibility and time saved. Synthetic tests alone do not meet this bar.

## Not implemented or claimed
No live data, network connectors, source authentication, portfolio management, financial recommendation, trading, web deployment or public release.
